# Epsilon Audio Plugins

**Free, open-source audio plugins from Epsilon Records, for macOS, Windows and Linux (VST3 · AU · CLAP · VST2).**

Every plugin is MIT-licensed, built on [DPF](https://github.com/DISTRHO/DPF), and ships as universal macOS, Windows x64 and Linux x64 builds from GitHub Actions. This repository is the index; each plugin lives in its own repo.

## How they fit together

```
Monolith ──filter──► Caldera ──filters──► Strata (filters in the feedback loop)
    │                   │
    │                   └──simplified──► Basalt (live version)
    ├──filter──► Obsidian ──modulation system──► Strata
    └──filter──► Flint (single filter + envelope follower)
```

- **Monolith's filter** is a style in Caldera, Obsidian, Strata and Basalt (where it's called *Fat*), and Flint is built on it.
- **Strata** combines Caldera's filters with Obsidian's modulation system.
- **Basalt** is Caldera with the modulation removed and the controls enlarged for live use.
- **Gneiss** is the first dynamics plugin, a stereo compressor with sidechain.
- **Mica** is the first mixing EQ.
- **Flint** is a small, CPU-light filter with an envelope follower.
- **Granite** is a look-ahead brickwall limiter for mastering.
- **Slate** is a gate and expander that can also be played from MIDI.
- **Magma** is a multiband distortion with its own drag-and-drop modulation system.
- **Talc** is a de-esser with single-vocal detection and linear-phase split-band processing.
- **Schist** is a multiband compressor and expander with freely placed bands.
- **Geode** is the first reverb, an algorithmic design with a decay rate EQ.
- **Malachite** is an acid bass synth with its own step sequencer, the first plugin based on classic hardware.

## Download

**The collection installer** puts any or all fifteen plugins in the right folders: a `.pkg` for macOS, an `.exe` for Windows and a `.tar.gz` with `install.sh` for Linux, each with a choice of plugins and formats. Get it from this repository's [Releases](../../releases) (tagged `suite-<date>`), and see the [install guides](https://plugins.epsilonrecords.com/install) for finding the plugins in Ableton Live, Logic Pro, FL Studio, Reaper and Bitwig.

The installers are built by the [`installers`](.github/workflows/installers.yml) workflow from each plugin's latest release ([`installers/`](installers)): every push builds them as workflow artifacts, and running the workflow by hand with **publish** ticked releases them. Release zips are checked against each plugin's `SHA256SUMS.txt`. The macOS package is signed and notarized when the `MACOS_INSTALLER_P12` (a Developer ID Installer certificate) and `NOTARY_*` secrets are set; until then it is unsigned, and the Windows installer is unsigned until a code-signing certificate is added.

### Install

| Platform | Copy | To |
|---|---|---|
| macOS | `.vst3` / `.component` / `.clap` | `~/Library/Audio/Plug-Ins/VST3` / `Components` / `CLAP` |
| Windows | `.vst3` (folder) / `.clap` | `C:\Program Files\Common Files\VST3\` / `CLAP\` |
| Linux | `.vst3` / `.clap` | `~/.vst3/` / `~/.clap/` |

**macOS:** builds are ad-hoc signed, not notarized. After copying, clear the quarantine flag for all Epsilon plugins at once:

```
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/*/{Monolith,Caldera,Obsidian,Strata,Basalt,Gneiss,Mica,Flint,Granite,Slate,Magma,Talc,Schist,Geode,Malachite}*
```

**MIDI on effects:** Caldera, Strata, Magma and Slate accept MIDI (key tracking, MIDI-triggered envelopes, LFO retrigger, MIDI modulation sources, gate triggering). In Logic Pro, insert them as **AU MIDI-controlled effects**; in other DAWs, route a MIDI track to the plugin.

## Common to every plugin

- **Factory presets** in a browser in the plugin header that searches names and categories as you type, with a star to keep presets in **Favourites**.
- **MIDI Learn and user presets** saved as small text files that load the same on every OS.
- **Built from published DSP techniques**: PolyBLEP oscillators, Zavalishin topology-preserving state-variable filters, one-pole envelopes.
- **Tests** in each repo's `tests/` folder.
- **Build from source** with DPF:

  ```
  git clone --recursive https://github.com/DISTRHO/DPF.git dpf
  make -C plugins/<Name>                    # Linux / macOS (macOS also builds the AU)
  make -C plugins/<Name> WINDOWS=true CC=x86_64-w64-mingw32-gcc CXX=x86_64-w64-mingw32-g++
  ```

## Clean-room note

Each plugin was written from scratch, working only from public press releases, product descriptions, manuals and contemporary reviews. The DSP, interface and presets are original work, and no code, binaries, firmware, presets, artwork or trademarks from other products were used. Third-party components, such as the DPF framework, are listed under License in each plugin's README.

Several plugins have had a major version that widened their feature set: version 2.0 for Gneiss, Mica, Granite, Magma and Geode, and version 3.0 for Caldera, Obsidian and Strata. Each is tested to render sessions from the previous major version bit-identically. The other 2.0 releases add A/B, undo/redo, hover tips and help to the earlier plugins, a Ducking style to Slate and an Inf:1 ratio to Schist.

Malachite starts a second line: classic hardware instruments, recreated the same way.

## Website

The [`site/`](site) folder is a static website for the series (no build step): the home page, [`install.html`](site/install.html) (install guides and troubleshooting, served at `/install`) and [`made.html`](site/made.html) (how the plugins are made, served at `/made`). It uses [Plausible](https://plausible.io) for cookie-free analytics, including download and task-filter events, and a [Buttondown](https://buttondown.com) newsletter form that appears once `BUTTONDOWN_USER` is set in `site/index.html`. Netlify serves it via [`netlify.toml`](netlify.toml); to preview locally, open `site/index.html` or run `npx serve site`.
