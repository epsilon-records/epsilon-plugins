How they're made

Written from scratch, in the open

Every Epsilon Audio plugin is an original program with an original interface. The source code, tests and build scripts for each one are public under the MIT licence.

Clean-room designs

Every plugin in the series is a clean-room design. Fourteen of the fifteen are original effects and instruments; the fifteenth, Malachite, starts a second line built around classic hardware instruments.

Each plugin was written from scratch, working only from public press releases, product descriptions, manuals and contemporary reviews. The DSP, interface and presets are original work, and no code, binaries, firmware, presets, artwork or trademarks from other products were used. Third-party components, such as the DPF framework, are listed under License in each plugin's README. Each plugin's repository keeps the notes on what it was built from.

Built on open foundations

All fifteen are built on DPF, which produces VST3, Audio Unit, CLAP and VST2 versions from one code base, and share code through epsilon-common. They use published DSP techniques: PolyBLEP oscillators, topology-preserving state-variable filters, half-band oversampling and EBU R128 loudness measurement. Every repository has a test suite, and new versions are checked to play older sessions the same way.
